Control an ESP32 quadruped robot via MQTT with real-time sensor monitoring and voice commands. Features movement controls (trot, crawl, directional), speed presets, ultrasonic distance feedback, and in-browser voice recognition.

Built with React, Bun, and MQTT. Use [Chrome or Edge](https://cuadrupedo-ui.vercel.app/) for voice support.
